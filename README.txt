HOKEJOVÉ NOŽE – AKTUALIZOVANÁ ONLINE VERZIA

Táto verzia zachováva Supabase ako spoločnú databázu.

NOVÉ:
- svetlý profesionálny dizajn: biela/modrá/červená, čierne písmo
- Typ noža s automatickým zoradením podľa počtu evidovaných kusov
- predvyplnené typy Bauer, CCM, True a RamonEdge
- tlačidlo inštalácie aplikácie na podporovaných mobiloch/prehliadačoch
- evidencia odoslania cez Packeta alebo Slovenskú poštu
- údaje zákazníka, dobierka, číslo zásielky, stav a dátum odoslania

DÔLEŽITÉ:
V index.html musí zostať tvoja aktuálna SUPABASE_URL a SUPABASE_KEY. Tento ZIP obsahuje prázdne hodnoty, pretože kľúče nie sú súčasťou exportu.

Packeta a Slovenská pošta sú zatiaľ evidované v aplikácii; priame vytváranie zásielok cez ich API bude potrebovať bezpečný serverový endpoint a API prístupy.
